# chuppa.gg

An independent gaming information hub by Ludy.

Website: [https://chuppa.gg/](https://chuppa.gg/)

## Problem

Game information is spread across guides, reference pages, rankings, and community discussions. Players need a starting point that connects these different kinds of information and lets them follow supporting sources.

## Features

- Beginner guides
- Character and item references
- Builds
- Tier lists
- Codes
- Game-focused discovery
- Sources for further reading

Coverage varies by game.

## How to use

1. Open [https://chuppa.gg/](https://chuppa.gg/).
2. Find the game you are interested in.
3. Choose the relevant guide or reference.
4. Read the context behind recommendations.
5. Follow sources when you need additional detail.

## Feedback

Useful feedback includes the page URL, the question you were trying to answer, and any source supporting a proposed correction.

Do not include account credentials or other private information.
